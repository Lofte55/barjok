## 4. ⚠️ ГЛАВНОЕ: грабли, на которые уже наступили

Читать обязательно перед правками — это стоило нескольких итераций.

### 4.1. «в границах улиц» — ПРОБОВАЛИ РАЗМЕЧАТЬ ОБЛАСТЬ, ОТКАТИЛИ
ПТС пишет: «ГВС приостановлено в домах **в границах улиц**: Камзина; Естая; Астана; …».
Соблазн: построить полигон и пометить все дома внутри.
Реализовали через выпуклую оболочку по **центроидам** улиц — вышло катастрофически неверно:
- Камзина тянется через весь город, её центроид **52.257 (ЮГ)**, хотя объявление про **СЕВЕР**
- Малайсары батыр «уехала» на **76.79 (запад)**
- Контур раздулся до **33 км², накрыл 71 % домов города** → карта стала «ковром» пиктограмм
- Лимит 3000 домов обрезал часть произвольно → «отключение есть, а на карте нет»

**Сейчас: размечаем только явно названные улицы** (33 % домов, 17 улиц из источника).
`parser/lib/geo.js` и `buildings.housesInPolygon()` оставлены, но **НЕ используются**.

### 4.2. Привязка карточки к дому
`outagesNear()` сопоставлял по улице **без ограничения расстояния** — для «Камзина, 37»
показывал наряд с «Камзина, 172» (километры). Сейчас: точный адрес → приоритет,
улица учитывается в радиусе 350 м, иначе 120 м.

### 4.3. Прочее (детали в barjok.md)
- **`map/app.js` обязан быть в IIFE** — `data.js` объявляет глобальные `const`, иначе `SyntaxError` и скрипт молча не выполняется.
- **Версии ассетов `?v=`** в `map/index.html` — без них браузер держит старый `app.js`. При правке css/js бампать.
- **GL-подложка:** не выставлять `z-index` контейнеру (карта белеет) и не убирать ресайз после монтирования.
- **`\b` в регулярках по кириллице не работает** — границы слов задавать явно.
- **Даты — «стенные» часы через UTC-геттеры**, иначе время едет по часовому поясу зрителя.
- **Демо-данные (`pavlodar-curated.js`) не домешивать к реальным** — один раз из-за этого карта показывала выдуманные аварии.
- **Vercel:** `cleanUrls:true` ломает rewrites (404); rewrite на директорию ломает относительные ассеты — `/map/` отдаётся нативно при `trailingSlash:true`.
- **В тестовом браузерном превью WebGL-карта скриншотится белой**, хотя реально отрисована. Проверять замером пикселей канваса, а не глазами.

## 6. Приоритеты для следующего чата (открытые вопросы)

1. 🔴 **Микрорайоны ГВС — СИСТЕМНЫЙ фикс (главное).** Сейчас улицы микрорайонов размечаются вручную
   курируемым списком `MICRODISTRICTS` в `pts-heat.js` (пользователь по одной жалуется — Павлова, Лермонтова,
   Баян батыра, Айманова…). Это не масштабируется. **Проблема:** OSM не знает границ микрорайонов
   (нет `addr:suburb` на домах, нет точек-центров — проверено Overpass), и район НЕ компактный
   (Айманова в 3.6 км от Павлова, но обе «Химгородки»). **Правильное решение:** reverse-geocode центра
   каждой улицы (координаты уже есть в `geocache.json`/`buildings.json`) через Nominatim → получить `suburb`
   → построить карту `улица→район` → когда ПТС называет микрорайон, размечать ВСЕ улицы с этим районом.
   ~700 reverse-geocodes (кэшируются, ~1 сек/шт = ~12 мин один раз). Это закроет вопрос «все у кого есть
   такой район» разом. Список ПТС-микрорайонов: Химгородки, Усольский, Сарыарка, Дачный, Достык, Зеленстрой,
   2-й Павлодар, Восточный, пос. Лесозавод (Северная промзона — индустриальная, не нужна).
2. 🟠 **PageSpeed — глубже.** Уже сделано: `defer` скриптов, preconnect, кэш-заголовки (`vercel.json`).
   Дальше (по отчёту web.dev для `/map/`): `data.json` ~1.3 МБ (Vercel гзипит до ~80 КБ, но можно
   пагинировать/грузить видимую область), ленивая загрузка maplibre-gl (тяжёлая либа), меньше весов шрифтов,
   критический CSS инлайном. ⚠️ Локально PDF-отчёт не прочитать (нет poppler) — открыть web.dev заново.
3. 🟠 **«Нет пина на доме».** Гранулярность номеров OSM: в реестре есть «7/1», нет «7». Клик по зданию «7»
   даёт reverse-geocode → карточка показывает отключение улицы, но пина на «7» нет. Фикс — пополнять реестр
   или помечать всю улицу линией (линии сейчас убраны намеренно). Обсудить с пользователем желаемое поведение.
4. 🟢 **Мультигород.** `parser/cities.js` (заготовки astana/almaty/…), для нового города:
   (а) внести источники в 🔒 реестр `barjok.md` → (б) адаптер `parser/adapters/<city>-*.js` → (в) `cities.js`.
   На фронте: `/map/<city>` уже роутится (vercel), дропдаун города готов; нужно грузить per-city `data.json`
   (сейчас один `/map/data.json`). **Экибастуз и Аксу — заполнить реестр источников первыми.**
5. **Газ** — источник не найден, фильтр «Газ» пуст. **OCR не нужен** — адреса ПТС лежат в тексте статей.
6. **Реклама** — скрыта флагом `ads-off` на `<body>` карты. Вернуть = убрать класс. Прайс/модалка контактов готовы.
7. Подписки/уведомления (Telegram/email) — отложены. Полная KK-локализация карты (в лендинге RU/KZ уже работает; на карте частично).
