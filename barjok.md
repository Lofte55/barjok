# barjok.md — Карта проекта «Бар Жоқ»

> v5 · Павлодар · 2026-08 · реальные парсеры (3 источника) · карта + лендинг разделены · автозапуск 3ч · Vercel
> Репозиторий: `github.com/Lofte55/barjok` (push по **SSH**) · Домен (план): `barjoq.kz`
> **ПРОД: https://barjok.vercel.app** — `/` лендинг · `/map/` карта · `/ads` реклама

**Что это.** Сервис показывает, когда в доме отключат воду/свет. Ввёл адрес → увидел отключения
именно по своему дому (дата, время, причина). Позиционирование: информация уже существует,
мы делаем так, чтобы её нашли за 5 секунд, а не за 20 минут.

## Свежие изменения (v7) — «в границах улиц» = ОБЛАСТЬ + номера домов + мобильный UX

- ⚠️ **«в границах улиц» — это ОБЛАСТЬ, а не список улиц.** ПТС пишет: «приостановлено ГВС
  в домах в границах улиц: Камзина; Естая; Астана; …». Раньше мы помечали только сами
  граничные улицы — из-за этого **Сатпаева 21/1 и Павлова оставались без ГВС**, хотя они
  внутри контура. Теперь строим выпуклую оболочку по граничным улицам (`parser/lib/geo.js`)
  и берём **все дома внутри** (`buildings.housesInPolygon`). **2820 → 4639 домов.**
  Защита: контуры < 0.2 км² и > 90 км² отбраковываются (тогда размечаем только улицы).
- **Номера домов на карте вернулись.** В стиле liberty **нет слоя `housenumber`**
  (в растровых тайлах CARTO он был). Данные в тайлах есть (`source-layer: housenumber`,
  z14, дальше растягивается) — добавляем слой сами в `localizeStyle()`.
  Заодно `localizeStyle` больше не затирает `text-field`, не относящийся к названиям
  (раньше затирал и номера домов — они исчезали).
- **Район был по-казахски** («Химқалашықтар»). В геокодер добавлен `accept-language=ru`,
  кэш районов сброшен → «Химгородки». ⚠️ При правках геокодера чистить `parser/geocache.json`.
- **Подсказки адресов** — справочник всех домов города (`map/addresses.json`, 737 улиц /
  39 623 адреса, 254 КБ gzip) грузится **лениво** при первом касании поиска.
  «Павлова 38» → «улица Павлова, 38», «38/1». ⚠️ Тег в подсказке считается по реальным
  данным (кол-во систем или «отключений нет») — не подписывать вслепую.
- **Мобилка:** поиск + RU/KK в одну строку; нижняя шторка по умолчанию **свёрнута**
  (акцент на карте), три состояния: свёрнута → половина → развёрнута.
- **Дедуп карточки:** соседние дома несут один и тот же наряд — показывало «6 систем»
  из копий. Дедуп по `ресурс|тип|начало|конец`.
- **Плавный пан:** `fitBounds` отменяется при первом касании карты (раньше откатывал вид
  через 900 мс); перерисовка маркеров отложена на 160 мс и только при смене зума/сдвиге.
- Вес: `data.json` 2.6 МБ → **79 КБ gzip** (Vercel жмёт), `addresses.json` — 254 КБ gzip.

## Свежие изменения (v6) — КОНКРЕТНЫЕ ДОМА вместо линий улиц + русские подписи карты

- **Дома, а не улицы.** Источник пишет «отключение ГВС на Кутузова» — раньше рисовали линию
  улицы. Теперь парсер **разворачивает улицу в конкретные дома**: `parser/lib/buildings.js`
  выкачивает из OSM (Overpass) адресный реестр Павлодара (~40 тыс. домов, 737 улиц) в
  `parser/buildings.json` и отдаёт `housesOnStreet('Кутузова')` → 25 домов с номерами.
  Результат: **44 «улицы» → 2820 реальных домов** (4003 отключения).
  Линия улицы осталась только как фолбэк, если улицы нет в реестре (5 случаев).
  ⚠️ Ключ сопоставления — самое длинное значимое слово (фамилия) после снятия типа
  («улица/көшесі/проспект»), титулов («академик/батыр») и падежных окончаний.
  Это чинит «Ак.Сатпаева» ↔ «улица Академика Сатпаева» ↔ «Академик Сәтбаев көшесі».
  ⚠️ `\b` в JS **не работает с кириллицей** — границы слов задавать явно (на этом уже обожглись).
- **Подписи карты на русском.** Растровые тайлы (CARTO) содержат «вшитые» подписи на местном
  языке — в Павлодаре казахские, переключить нельзя. Перешли на **векторные тайлы
  OpenFreeMap** (`tiles.openfreemap.org/styles/liberty`, бесплатно, **без API-ключа**)
  через `maplibre-gl` + `maplibre-gl-leaflet`. В `localizeStyle()` подменяем `text-field`
  во всех слоях-подписях на `name:ru` / `name:kk` → подписи переключаются вместе с интерфейсом.
  (Wikimedia `osm-intl` проверен — 403 для внешних сайтов, MapTiler требует ключ.)
- ⚠️ **Две грабли GL-подложки** (обе уже словили, не повторять):
  1. **Не выставлять `z-index` контейнеру GL-слоя.** Он лежит в `leaflet-tile-pane`;
     любой явный z-index прячет подложку — карта белая.
  2. **Слой добавляется асинхронно** (после `fetch` стиля), уже после того как `load()`
     отработал свои `invalidateSize`/`fitBounds`. Без явного ресайза после монтирования
     GL-канвас не синхронизирован и карта белая. Пинаем `invalidateSize()` + `resize`.
- ℹ️ В тестовом браузерном превью WebGL-канвас часто **скриншотится белым**, хотя реально
  отрисован. Проверять не глазами, а замером пикселей канваса (`drawImage` → `getImageData`).

## Свежие изменения (v5) — разделение лендинг/карта + подсветка улиц + фикс поиска

- **Структура разделена** на `landing/` и `map/` (было: лендинг в корне, карта в `app/`).
  Маршрутизация — через `vercel.json` rewrites: `/` → лендинг, `/map` → карта, `/ads` → рекламодателям.
  ⚠️ Парсер теперь пишет в **`map/data.json`** (не `app/`).
- **Подсветка улицы целиком.** Если источник указывает только улицу («ГВС на Кутузова»),
  подсвечивается **вся улица** линией цвета ресурса, а не одна точка. Геометрия — Nominatim
  `polygon_geojson=1`, поле `geom` в доме (массив путей `[[lat,lng],…]`), флаг `streetWide`.
  Аварийные — пунктиром. Клик по линии → карточка. Сейчас геометрия у 40 из 44 домов.
- **Фикс поиска (был сломан).** Раньше «Лермонтова 44» не находилось: поиск делал точное
  вхождение подстроки и был привязан к фильтру времени. Теперь:
  `parseQuery()` разбирает «улица + номер дома», `streetMatches()` сравнивает с учётом
  падежей/сокращений, а если адреса нет в данных — **геокодим через Nominatim** и показываем
  карточку «Отключений нет — вода и свет в порядке». Это и есть ответ сервиса.
- **Клик по любому дому.** `map.on('click')` → reverse-geocode → карточка адреса
  (с отключениями рядом или «отключений нет»). Раньше кликались только дома с отключениями.
- **Кэш-бастинг ассетов** (`?v=timestamp` у css/js) — иначе браузер держал старый `app.js`.
- ⚠️ **Язык карты.** Растровые тайлы CARTO содержат «вшитые» подписи на местном языке
  (в Павлодаре — казахский), поэтому при RU интерфейсе подписи остаются казахскими.
  Инфраструктура переключения готова (`setTiles(lang)`, `TILE_KEY`), но нужен провайдер
  с параметром языка — **MapTiler** (бесплатный ключ). Вставить ключ в `map/app.js` → `TILE_KEY`.
  Wikimedia `osm-intl` проверен — отдаёт 403 для внешних сайтов, использовать нельзя.

## Как обновить данные

```bash
node parser.js              # активный город (Павлодар)
node parser.js novosibirsk  # другой город из реестра
./parser/run.sh pavlodar    # то же + лог + защита от битых данных
```
Требуется системный `unzip` и сеть. Первый прогон геокодит улицы (~1.2 с/шт), дальше — кэш.

**Расписание — каждые 3 часа** (`StartInterval 10800`). Обоснование: источники обновляются
раз в сутки, но аварии могут выйти в любой момент; 3 ч = свежесть в пределах 3 ч при
минимальной нагрузке на чужие сайты. Реже — риск проспать аварию, чаще — бессмысленно.

```bash
cp parser/com.barjoq.parser.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/com.barjoq.parser.plist    # запустить
launchctl unload ~/Library/LaunchAgents/com.barjoq.parser.plist  # остановить
```
⚠️ LaunchAgent — только для локальной машины. Для прода — cron на VPS
(`0 */3 * * * /path/parser/run.sh pavlodar`) или GitHub Actions с коммитом `map/data.json`.

## Что НЕ трогать без понимания

- **`map/app.js` обёрнут в IIFE.** `data.js` объявляет глобальные `const` (`RESOURCES` и т.д.);
  без IIFE происходит `SyntaxError: Identifier already declared` и скрипт молча не выполняется.
- **Leaflet + размер контейнера.** Тайлы рисуются частично, если карта инициализируется до
  финального лэйаута. Лечится `ResizeObserver` + `invalidateSize()` — уже стоит, не удалять.
- **Версии ассетов `?v=`** в `map/index.html`. Без них браузер держит старый `app.js`.
  При правке css/js — бампнуть версию (или деплой на Vercel, там свои хеши).
- **Даты — «стенные» часы, записанные как UTC.** Форматирование через UTC-геттеры
  (`getUTCHours` и т.д.), иначе время поедет на часовой пояс зрителя.
- **`NOW` в адаптерах** зашит как `Date.UTC(2026,7,3,12,0)` — опорная дата продукта.
  В проде заменить на `Date.now()`.
- **Демо-данные (`pavlodar-curated.js`)** — только аварийный фолбэк. Не домешивать к реальным:
  из-за этого карта один раз показывала выдуманные аварии.
- **`parser/buildings.json` (2.6 МБ) не в git** — качается один раз с Overpass при первом
  запуске парсера. Пересоздать: удалить файл или `node -e "require('./parser/lib/buildings').refresh()"`.
- **GL-подложка:** не трогать z-index контейнера и не убирать ресайз после монтирования
  (см. v6) — иначе карта белая.
- **`\b` в регулярках по кириллице не работает.** Границы слов задавать явно.

## Деплой (Vercel) — РАБОТАЕТ

**Прод: https://barjok.vercel.app** — деплоится автоматически на каждый `git push` в `main`.

Настройки проекта: Framework Preset **Other**, Root Directory `./`, Build Command и
Output Directory — **пустые** (чистая статика, маршруты из `vercel.json`).
Домен `barjoq.kz` подключается в Vercel → Settings → Domains.

### ⚠️ Грабли деплоя (были 404 — не повторять)

1. **`cleanUrls: true` ломает rewrites.** Он делает `/landing/index.html` доступным как
   `/landing`, и destination рерайта перестаёт резолвиться → 404 на `/`. **Не включать.**
2. **Rewrite на директорию ломает относительные ассеты.** Было
   `{"source":"/map","destination":"/map/index.html"}` — URL в браузере оставался `/map`
   (без слэша), поэтому `styles.css` резолвился в `/styles.css` → 404, карта грузилась
   голой (гигантские SVG без CSS).
   **Решение:** `"trailingSlash": true` + **никакого рерайта на `/map`** — Vercel сам
   отдаёт `map/index.html` для `/map/`, и относительные пути работают.
   Ссылки на карту вести как `/map/` (со слэшем).
3. Рерайты нужны только там, где путь ≠ папке: `/` → `landing/index.html`, `/ads` → `landing/ads.html`.
