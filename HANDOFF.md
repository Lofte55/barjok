## 4. ⚠️ ГЛАВНОЕ: грабли, на которые уже наступили

Читать обязательно перед правками — это стоило нескольких итераций.

### 4.1. «в границах улиц» — ПРОБОВАЛИ РАЗМЕЧАТЬ ОБЛАСТЬ, ОТКАТИЛИ
ПТС пишет: «ГВС приостановлено в домах **в границах улиц**: Камзина; Естая; Астана; …».
Соблазн: построить полигон и пометить все дома внутри.
Реализовали через выпуклую оболочку по **центроидам** улиц — вышло катастрофически неверно:
- Камзина тянется через весь город, её центроид **52.257 (ЮГ)**, хотя объявление про **СЕВЕР**
- Малайсары батыр «уехала» на **76.79 (запад)**
- Контур раздулся до **33 км², накрыл 71 % домов города** → карта стала «ковром» пиктограмм
- Лимит 3000 домов обрезал часть произвольно → «отключение есть, а на карте нет»

**Сейчас: размечаем только явно названные улицы** (33 % домов, 17 улиц из источника).
`parser/lib/geo.js` и `buildings.housesInPolygon()` оставлены, но **НЕ используются**.

### 4.2. Привязка карточки к дому
`outagesNear()` сопоставлял по улице **без ограничения расстояния** — для «Камзина, 37»
показывал наряд с «Камзина, 172» (километры). Сейчас: точный адрес → приоритет,
улица учитывается в радиусе 350 м, иначе 120 м.

### 4.3. Прочее (детали в barjok.md)
- **`map/app.js` обязан быть в IIFE** — `data.js` объявляет глобальные `const`, иначе `SyntaxError` и скрипт молча не выполняется.
- **Версии ассетов `?v=`** в `map/index.html` — без них браузер держит старый `app.js`. При правке css/js бампать.
- **GL-подложка:** не выставлять `z-index` контейнеру (карта белеет) и не убирать ресайз после монтирования.
- **`\b` в регулярках по кириллице не работает** — границы слов задавать явно.
- **Даты — «стенные» часы через UTC-геттеры**, иначе время едет по часовому поясу зрителя.
- **Демо-данные (`pavlodar-curated.js`) не домешивать к реальным** — один раз из-за этого карта показывала выдуманные аварии.
- **Vercel:** `cleanUrls:true` ломает rewrites (404); rewrite на директорию ломает относительные ассеты — `/map/` отдаётся нативно при `trailingSlash:true`.
- **В тестовом браузерном превью WebGL-карта скриншотится белой**, хотя реально отрисована. Проверять замером пикселей канваса, а не глазами.

## 6. Приоритеты для следующего чата

1. ✅ **GitHub Actions по cron** — СДЕЛАНО (`.github/workflows/parser.yml`, каждые 3 ч, коммит `data.json`).
   Заодно `NOW` в адаптерах переведён на `Date.now()` (было зашито 03.08.2026) — иначе живой cron
   вечно фильтровал бы отключения относительно 3 августа. Пин для теста: env `BARJOQ_NOW=2026-08-03T12:00:00Z`.
2. **Микрорайоны в разметке ГВС.** Полигонов в OSM нет. ⚡ Новый заход: на `pavlodarenergo.kz` есть
   файлы `…grafik-zapuska…gotovnosti-zhilyh-domov-{yuzhnogo,severnogo}-setevogo-rajona-pavlodara.docx`
   — «графики запуска и степень готовности жилых домов» по Южному/Северному сетевому району. Там могут
   быть КОНКРЕТНЫЕ адреса домов с датами запуска ГВС → распарсить их как ГВС-источник (сейчас исключены
   из электро-парсера по маске `grafik|gotovnosti`). Прочие подходы:
   - переcкачать `buildings.json` из Overpass **с тегом `addr:suburb`** и матчить дома по названию микрорайона (самое надёжное);
   - либо назначение по ближайшей точке-центру микрорайона с ограничением радиуса (аппроксимация — сначала проверить количество домов, не повторять ошибку 4.1).
3. **Абая — 1 дом.** Разобраться с нормализацией ключа улицы в `parser/lib/buildings.js` (`normStreet` берёт самое длинное значимое слово; для коротких названий это может сбоить).
4. **OCR картинок ПТС** — часть объявлений публикует адресные списки только картинкой. Закроет основной пробел по ГВС.
5. **Источник по газу** — не найден, фильтр «Газ» пуст.
6. **Реклама** — сейчас скрыта флагом `ads-off` на `<body>`. Вернуть = убрать класс. Инвентарь и цены на `/ads`.
7. Подписки/уведомления (Telegram/email) — **сознательно отложены**, кнопки скрыты.
8. Полная KK-локализация лендинга (в карте RU/KK уже работает).

## 7. Быстрые команды

```bash
# обновить данные
node parser.js                 # активный город (Павлодар)
node parser.js novosibirsk     # другой город из реестра
./parser/run.sh pavlodar       # то же + лог + защита от битых данных

# планировщик (каждые 3 часа)
launchctl load   ~/Library/LaunchAgents/com.barjoq.parser.plist
launchctl unload ~/Library/LaunchAgents/com.barjoq.parser.plist

# пересобрать адресный реестр OSM (если удалить buildings.json — скачается сам)
node -e "require('./parser/lib/buildings').refresh()"

# деплой
git push origin main           # Vercel подхватит автоматически
```
